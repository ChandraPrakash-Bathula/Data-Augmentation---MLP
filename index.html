Data Foundations & Deep Learning Basics

Every model you'll build in this course, from a tiny MLP to a Transformer, does the same thing underneath: it turns data into tensors and learns a function over them. When there isn't enough data, we augment it. This week covers both.

How to use this guide

Each topic is explained in three layers. The same colours are used on every page:

What

The definition: what the operation or technique actually is.

How

The mechanics: the code you'd write in NumPy / PyTorch / torchvision, and what happens to the numbers.

Why

The reasoning: what problem it solves, when it helps, and when it quietly hurts your model.

Most pages also have live demos you can play with in the browser. They don't need Python or an internet connection.
